# Development roadmap / Entwicklungsplanung

## V0.5A FIX2 — hardware-validated baseline
Ten-channel synthesis, touchscreen editor, kit storage, ten-track sequencer, A/B/C/D variations, 16/32/64 steps, velocity, accent, swing, recording, MIDI synchronization and persistent pattern management. Stabilized external BPM display.

## V0.6A — advanced sequencing (development, hardware validation pending)
- Probability 0–100%, ratchets 1–8, microtiming.
- One parameter lock per step.
- Independent track lengths (1–64 steps), playback directions.
- Pattern chaining, copy, clear and randomize.
- Advanced Step Editor and Pattern V2 with V1 compatibility.

## V0.7A — song and performance (planned)
Song arrangement and expanded pattern chaining, live performance workflows and transitions. Exact scope subject to testing.

## V0.8A — optimization and MIDI (planned)
Real-time performance profiling, MIDI workflow refinement, storage reliability and regression testing.

## Parallel Sound Matcher development
Experimental offline WAV analysis and synthesis optimization; planned improvements include multi-stage fitting, instrument classification, native kit export, Windows GUI, complete ten-instrument kits and batch processing.

## Release readiness
Hardware regression testing, documentation, preset quality, licensing audit and reproducible firmware packaging. No release date is promised.
